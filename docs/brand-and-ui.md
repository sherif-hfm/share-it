# Share-It brand and interface

**Your workspace, across machines.** Share-It is a calm, precise developer utility. The paired-window mark represents moving a small piece of work between machines. Assets are in `wwwroot/brand`; the mark also serves as the favicon.

Dark is the default. The theme button cycles Dark, Light, and System; only this non-sensitive preference is stored in localStorage. Inter is used for the interface, JetBrains Mono for commands and codes; both are self-hosted with their licenses. No analytics, font CDN, or third-party browser request is required.

Semantic colors and typography live in `css/tokens.css` and `css/themes.css`. Charcoal/teal is the primary palette; red is destructive/error feedback and amber signals expiry. Corners, borders, spacing, and interaction states are shared rather than customized separately for each screen. The layout uses a wide two-column workspace, switching to text/file tabs below 1100px.

Key interaction rules: explicit text saves; exact saved-content copying; visible copied feedback; PIN shown only on creation; no PIN in share links or curl commands; preserved drafts on conflict; progress/cancellation for uploads; clear connection status; destructive confirmation for ending/deleting. Ending a session focuses the non-destructive choice and explains deferred retention if deletion is unchecked.

Accessibility target is WCAG 2.2 AA. All actions use semantic controls with names and focus indicators. Native dialogs provide modal focus containment; Escape cancels. Motion respects reduced-motion preferences. Test both themes, 1024×768 RDP, narrow layouts, and reflow equivalent to 200% zoom. Visual review screenshots are generated by the browser tests under `.artifacts/screenshots/`.
